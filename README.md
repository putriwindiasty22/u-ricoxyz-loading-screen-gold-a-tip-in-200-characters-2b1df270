## The tip

> Tip: your AI agent is re-reading your prompt for the fifth time, hoping the requirements changed while it wasn't looking.

One line, 121 characters. A loading-screen tip for stressed developers and AI coding agents: the agent stalls mid-build, re-reading the prompt and quietly hoping the requirements changed on their own — the exact thought a tired developer has while staring at the spinner, and the exact thing an agent would never admit. No coffee, no deadline, no compile joke.

## How to run

Requires Node 22 or later. No dependencies, no network.

```sh
node main.ts
```

This writes the tip to `/output/entry.txt` when that directory is available, and to `./output/entry.txt` when run locally. It reads the file back and verifies the written text matches the tip exactly.
